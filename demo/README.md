# Demo

## Purpose

This folder is for the AR Suraksha prototype/demo materials used to communicate the proposed product experience.

## Demo status

The current SIH presentation/demo materials should be treated as **prototype representation** unless the corresponding feature has been implemented and tested.

## Recommended demo flow

1. Product introduction
2. Language selection
3. Safety module selection
4. AR scenario
5. Hazard identification
6. PPE/response selection
7. Assessment feedback
8. Certificate/verification concept
9. Offline-first and synchronization concept

## Adding media

Large binary files such as videos should be handled carefully. GitHub recommends Git LFS for large files when appropriate. Keep the repository focused on source code and essential documentation.
