## Reference-use note

The sources above cover different purposes. DGMS and OSHA references concern safety/regulatory context; the systematic review provides research context for AR safety training; the remaining sources document the proposed technical stack.

OSHA material is included as general international safety guidance and should not be represented as Indian statutory law.

The Unity reference points to AR Foundation 4.2 documentation; the implementation should verify the documentation/version corresponding to the actual Unity package used.
