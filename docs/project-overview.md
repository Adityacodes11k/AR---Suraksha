# Project Overview

## AR Suraksha

**AR Suraksha** is the proposed solution from Team Adyzen for SIH 2026 problem statement **SIH26041**.

### Objective

Create an offline-first, mobile AR training experience that allows industrial workers to practise safety scenarios, make guided decisions, receive immediate assessment feedback, and retain verifiable training results.

## Intended users

- Industrial workers and trainees
- Safety trainers
- Site administrators
- Organizations responsible for worker training and compliance records

## Key product flow

```text
Language
   ↓
Safety Module
   ↓
AR Scenario
   ↓
Hazard Identification
   ↓
PPE / Response Selection
   ↓
Assessment + Feedback
   ↓
Offline Result Storage
   ↓
Online Synchronization
   ↓
Certificate / Admin Record
```

## Proposed MVP

The source project plan identifies a three-month MVP around:
- Fire scenario
- Gas-leak scenario
- Quiz / assessment
- QR certificate

## Design principles

1. **Offline-first** — training should remain usable without continuous connectivity.
2. **Mobile-first** — avoid requiring dedicated VR headsets for the proposed workflow.
3. **Simple interaction** — support users with limited digital literacy.
4. **Regional language support** — Hindi and Santali are part of the proposed experience.
5. **Verifiable outcomes** — assessment results and certificates should be traceable.
6. **Transparent implementation status** — planned features are not presented as completed software.
