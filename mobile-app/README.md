# Mobile App

## Proposed role

The worker-side Android application is the primary user-facing component of AR Suraksha.

## Proposed stack

- Unity
- C#
- AR Foundation
- Google ARCore
- SQLite

## Planned modules

```text
Home
 ├── Language
 ├── Safety Modules
 │    ├── Fire
 │    └── Gas Leak
 ├── Training
 ├── Assessment
 └── Certificate
```
